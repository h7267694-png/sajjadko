## ما تشمله خدمة حفر السجاد

| البند    | التفاصيل                              |
| -------- | ------------------------------------- |
| الخدمة   | حفر ونقش يدوي حسب النقشة              |
| ما نحفره | السجاد والزوالي                       |
| المرجع   | نقشتك: صورة أو ملف                    |
| المقاس   | حسب طلبك                              |
| السعر    | يُحدد بعد معرفة النقشة والمقاس        |
| الطلب    | عبر واتساب فقط، ولا يوجد بيع إلكتروني |

## خطوات طلب حفر السجاد

1. أرسل صورة النقشة أو ملفها عبر واتساب مع المقاس ونوع المكان.
2. نراجع النقشة معك.
3. نؤكد معك السعر والمقاس قبل البدء.
4. ننفذ الحفر اليدوي ونسلّمك العمل.

## ما نحتاجه منك لحفر السجاد

- صورة النقشة أو ملفها.
- مقاس السجاد أو الزولية بالمتر.
- نوع المكان الذي ستوضع فيه.
- صورة السجاد الجاهز إن كان عندك سجاد تريد نقشه.

## السجاد المحفور والمطبوع

السجاد المحفور تُنفَّذ نقشته يدويًا في السجاد نفسه، والمطبوع تُطبع نقشته على سطحه. اختيار أحدهما يغيّر شكل النتيجة، لذلك أرسل لنا النقشة التي تريدها ونوضح لك الأنسب لها.
