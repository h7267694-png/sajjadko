# نظام الفواتير وعروض الأسعار + باركود التحقق

- التطبيق: `https://sajjadko.com/invoice/` (يعمل من الجوال، ويُثبَّت كتطبيق من «إضافة إلى الشاشة الرئيسية»).
- صفحة التحقق: `https://sajjadko.com/verify/` (عليها `noindex`، وتطبيق الفواتير ممنوع في `robots.txt`).
- كلاهما خارج حواجز الجودة وخارج خريطة الموقع (ملفات ثابتة في `public/`).

## الملفات
| المسار | الوظيفة |
|---|---|
| `public/invoice/config.js` | الاسم والهاتف والمستودع والترقيم والشروط |
| `public/invoice/codes.json` | الأصناف والخامات ووحدات السعر ومدد الضمان |
| `public/verify/index.html` | صفحة التحقق |
| `public/verify-keys.json` | المفاتيح العامة للأجهزة المفعّلة |
| `scripts/fetch-invoice-vendor.mjs` | يجلب html2canvas و jsPDF و qrcode-generator وقت البناء (إصدارات مثبّتة + SHA-256) |

## قواعد
- **لا تغيّر رقم رمز في `codes.json` بعد إصدار فواتير به** — الباركود يحفظ الرقم. أضف أرقامًا جديدة فقط.
- عند تغيير البادئة أو رقم البداية في `config.js` ارفع `numbering.version` ليُطبَّق على الأجهزة المستخدمة.
- الاسم والهاتف والترقيم والشروط تُعدَّل أيضًا من «الإعدادات» داخل التطبيق.
- لا يُرفع أي توكن داخل ملفات الموقع.

## تفعيل جهاز (مرة لكل جوال)
1. افتح `/invoice/` ← **الإعدادات** ← «باركود التحقق».
2. الصق توكن GitHub من نوع Fine-grained بصلاحية **Contents: Read and write** على مستودع `sajjadko` فقط.
3. اضغط «تفعيل التحقق على هذا الجهاز». يُرفع المفتاح العام إلى `public/verify-keys.json` وينشر الموقع نفسه.
4. احذف التوكن من GitHub بعد التفعيل إن أردت — الجهاز يبقى مفعّلًا.

## كيف يعمل التحقق
- عند حفظ **فاتورة** (وليس عرض سعر) يوقّعها التطبيق (ECDSA P-256) بمفتاح خاص لا يمكن نسخه من الجهاز.
- الباركود يحمل فقط: رقم الفاتورة، التاريخ، ولكل بند صنفه وخامته ومدة ضمانه. لا اسم ولا هاتف ولا مبلغ.
- أي تعديل في الرابط = «لم نتمكن من التحقق».
- الفواتير محفوظة داخل الجوال: خذ «نسخة احتياطية للأرشيف» بانتظام.
